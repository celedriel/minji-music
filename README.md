# Minji Music Bot

bot de música feito em **Python**, utilizando as bibliotecas `disnake` e `yt-dlp`. Rodando 100% via **Slash Commands** (`/`).

---

### Recursos

* **Slash Commands (`/`)**: Interação nativa direto no chat do Discord.
* **Embeds Estéticos**: Textos, cores e imagens dos embeds são totalmente opcionais e você pode editar de acordo com as preferências e a estética do seu servidor.
* **Filtros de Áudio**: Suporte integrado para efeitos de áudio, como o modo *nightcore*.
* **Controle Completo**: Sistema inteligente de fila, avançar (skip), misturar (shuffle), modo repetição (loop) e controle de volume.

---

### Pré-requisitos

Antes de iniciar o bot, certifique-se de ter instalado em sua máquina:
* **Python 3.9** ou superior.
* **FFmpeg** (obrigatório para o bot conseguir processar e reproduzir os áudios no canal de voz).

---

### Instalação e Uso

**1.** Clone este repositório para a sua máquina.

**2.** Instale todas as dependências necessárias através do `requirements.txt`

**3. Autenticação:**
Abra o arquivo main.py e insira o Token do seu bot na variável correspondente, ou configure uma variável de ambiente chamada TOKEN.

**4. Inicie o bot:**

Se estiver no Windows:

````
Bash
python main.py
````

Se estiver rodando no Linux:
````
Bash
python3 main.py
````
